# Decision record template (ARCH-016)

Copy to `docs/decisions/NNNN-<short-slug>.md` (numbered, never renumbered).
Keep it under one page.

```markdown
# NNNN — <decision in one line>

- Status: accepted | superseded by NNNN | proposed
- Date: YYYY-MM-DD
- Area: <packages / subsystem affected>

## Context
What forces the decision: constraints, requirements, what went wrong.

## Decision
What we do, stated so an agent can check code against it.

## Alternatives rejected
- <option>: why not.

## Consequences
What this makes easy, what it makes hard, and what must stay true (tests or
rules that protect it).
```
